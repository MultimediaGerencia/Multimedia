# Multimèdia Tarragona

Repositorio de trabajo de **Multimèdia Tarragona**, centro de formación reglada y ocupacional con más de 30 años de trayectoria.

## Propósito

Espacio para guardar y versionar los materiales y herramientas del equipo:

- Materiales formativos (certificados de profesionalidad, formación continua, formación para directivos públicos).
- Documentación de proyectos con clientes (EAPC, ICIQ, Port de Tarragona, etc.).
- Plantillas, guías internas y recursos de soporte pedagógico.

## Protección de datos

Este repositorio **no debe contener datos personales** de alumnado, docentes ni clientes, ni datos de categorías especiales (art. 9 RGPD). Cuando sea necesario trabajar con listados o encuestas, usar datos seudonimizados.
